# FolioWeave documentation

Each page answers one kind of question. Pick the group that matches what you are doing.

## Making your site

| Page                                     | Read it when                                                               |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| [QUICKSTART.md](QUICKSTART.md)           | You have just cloned the repository and want your own site running.        |
| [PERSONALIZATION.md](PERSONALIZATION.md) | You need to know what a field in `portfolio.json` does.                    |
| [RECIPES.md](RECIPES.md)                 | You want a copyable example: add a project, a post, photography, a resume. |
| [DEPLOYMENT.md](DEPLOYMENT.md)           | You are publishing the site, or want to know how the public demos update.  |
| [UPGRADING.md](UPGRADING.md)             | You are bringing a newer FolioWeave into an existing site.                 |
| [COMMANDS.md](COMMANDS.md)               | You want to know which command to run.                                     |
